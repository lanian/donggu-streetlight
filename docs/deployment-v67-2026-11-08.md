## 배포 전 검증

- 배포 후보 Node 459개, v61 포함 개발 폴더 Node 547개 통과.
- 새 원본 대장 반입 브라우저 8개·연계 화면 브라우저 19개를 두 폴더에서 통과. 기존 보수 업무·시설 흐름·보고서 출력·PC 화면 회귀도 통과.
- 규격 검토 PASS. 품질 검토에서 발견한 반복 취소의 원본 사진 요청 누적과 취소 후 다음 페이지 조회를 수정하고 재검토를 통과했다. 사진은 계정·DB·Firebase·namespace별 진행 중 요청만 공유하고 완료 결과는 영구 캐시하지 않는다.
- 실제 앱 주간·야간 1280/390px 캡처 12개 확인. 기본 연락처 제외·원본 사진·긴 메모·정상 기록·검수 상태·실제 ZIP MIME/CRC·파일 해시, 재내보내기·새로고침 이력 보존, CAS 충돌과 원본 불변을 검증했다.
- 원본 사진 60개 조회가 정지해도 실제 요청 3개를 유지하고 대체 여부를 표시한다. 241개 사진 참조를 자르지 않는다. 다른 계정의 응답과 이전 GAL 캐시를 섞지 않는다.
- Python 표준 zipfile로 실제 ZIP 헤더·CRC·파일별 SHA-256과 JSON 원문을 재확인했다.

모든 검증은 Firebase와 외부 호스트를 차단한 합성 자료 환경이다. 실제 운영 사이트 접수·수정, 운영 계정 인증, 업체 업로드 양식 호환을 검증한 결과가 아니다. 현재 지원 범위는 자료 반입·전달 파일·기기별 사용자 등록 확인이다.

## 공개 배포 확인

파이프라인 `42440419844`는 앱 검사·Functions/권한 규칙 검사·브라우저 43개 스크립트·Pages 배포를 모두 통과했다. 공개 페이지의 `v67-roadlighting`과 지정 10개 자산의 SHA-256이 커밋의 Git blob과 일치함을 확인했다.

공개 사이트에서도 Firebase 설정을 null로 바꾸고 외부 호스트·서비스 워커·비조회 HTTP 요청을 차단한 독립 브라우저에서 합성 자료만 검증했다. 원본 대장 비교의 출처 제한·누락 철거 금지, 정상 포함 점검·신고·보수·처리 이력·순찰, 원본 사진 3개, 긴 메모 1,514자와 연락처 기본 제외를 확인했다. ZIP 12개 파일의 CRC와 사진·파일별 SHA-256이 일치했고 Python zipfile로 실제 다운로드 2개를 다시 판독했다.

사용자가 입력한 합성 등록번호는 재내보내기·페이지 새로고침 뒤에도 유지됐다. 동일 묶음 ID와 내보낸 횟수 2회가 유지됐고 원래 검수 대기 작업의 상태는 `completed` 그대로였다. 서버 등록 검증 여부는 false다. 브라우저 오류·운영 등록/수정 요청은 모두 0건이다.
