# v66 보고서 출력 개선

기간 보고서·사진 대지·등 이력서·통합 업무 이력·업무 현황에 공통 출력 사본을 사용한다. 원래 화면·History·스크롤·초안은 유지하며, 사진과 글꼴을 준비한 뒤 인쇄 창을 연다. 준비 중 화면·조건·계정·저장소가 바뀌면 이전 출력을 취소한다. 브라우저 인쇄 창을 열었다는 사실과 실제 종이/PDF 저장 성공은 구분한다.

## 출력 구성

- A4 세로 여백, 표 머리글 반복, 긴 문자열 줄바꿈, 페이지 번호와 문서 바닥글을 제공한다. QR 표찰은 별도 라벨 페이지 서식과 기존 실제 치수를 사용한다.
- 기간 보고서는 기본 이상 발견 내역과 전체 점검 내역을 선택할 수 있다. 미리보기의 100건/150시설·사진 48장/24장 제한은 인쇄에 적용하지 않는다.
- 600자 초과 또는 줄 수가 많은 메모는 표에서 번호로 연결하고 전체 내용을 별도 부록에 보존한다. 불량 항목 요약은 상위 6종으로 자르지 않는다.
- 가로·세로 사진은 원본 비율을 유지한다. 같은 작업·점검의 조치 전후는 한 묶음으로 배치하고 사진과 캡션을 함께 출력한다. 원본 조회나 이미지 표시 실패는 증빙 옆에 표시한다.
- 현재 시설이 없는 동의 과거 점검과 행정동 미확인 기록도 동별 합계에 포함한다. 현재 시설·조치 필요 현황과 기간 점검 건수를 구별하고, 반복 점검 및 순찰 세션 전체의 누적 통과 집계 기준을 적는다. CSV의 기존 8열 계약과 원본 날짜·기록은 유지한다.
- 업무 현황의 반복 고장 목록은 두 단으로 배치한다. 화면에서 버튼인 자료 행도 출력 사본에서는 내용을 보존한다.

브라우저 출력 창은 **A4·세로·배율 100%**를 기준으로 한다. 자체 머리글·바닥글을 끄면 URL·제목 중복을 줄일 수 있다. 페이지 번호는 지원 브라우저의 인쇄 여백 기능을 사용한다.

## 검증 범위

Firebase와 모든 외부 요청을 차단한 독립 체험 환경에서 합성 기록·사진으로 확인한다. 실제 운영 계정 자료, 물리 프린터, 현장 촬영 증빙을 사용한 검증은 아니다. 기존 Firebase·주민 접수·서버 규칙·Functions 설정은 이번 변경에 포함하지 않는다.

검증 결과와 공개 배포 확인은 배포 기록에 남긴다. 앱 사용자는 미전송 기록·초안을 확인한 뒤 **새 버전 적용**으로 갱신한다.

로컬 검사에서는 배포 후보의 Node 419개와 별도 v61 개발 폴더의 Node 507개가 통과했다. 공통 출력 수명주기 15개·실제 앱 출력 15개 시나리오를 두 폴더에서 통과했고, 기존 사진 120장 출력·시설 업무 흐름·데스크톱·다크 모드 검사도 통과했다. 새 검사 두 스크립트를 전체 브라우저 CI에 추가했다.

동일 합성 자료의 PDF 비교 결과는 기간 보고서 13→10쪽, 사진 대지 4→2쪽, 업무 현황 3→2쪽이다. 추가로 발견한 시설 이력서의 좁은 내용 열과 긴 메모 분할을 고쳐 13→7쪽으로 줄였으며, QR의 안내만 있는 첫 페이지를 제거해 24개를 2쪽에 출력한다. 최종 5종 23쪽을 렌더해 확인했다. 20건의 메모 전체·불량 8종·사진 8종이 보존됐고, 빈 페이지·페이지 밖 텍스트·사진 캡션 분리·페이지 번호 오류는 발견되지 않았다. 보통 QR 30mm 설정은 print DOM 및 PDF 벡터 경계에서 약 29.997mm로 확인했다. 물리 프린터의 배율과 여백은 별도다.
