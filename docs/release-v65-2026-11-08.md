# v65 지도 마커 수정

운영 기준 v64 위에 지도 표시·선택의 네 가지 문제를 수정했다. 앱과 서비스 워커 버전은 `v65-markers`다.

## 동작

- 확대 지도에서 가까운 시설은 숫자로 묶고 누르면 표찰 번호·종류·상태 목록을 표시한다. 시설을 고르면 기존 상세 카드가 열리고 목록으로 돌아갈 수 있다. 실제 대장의 동좌표 39개를 각각 선택할 수 있다. 추정 좌표에는 현장 확인 안내를 제공하며 원본 좌표를 움직이지 않는다.
- 묶음의 대표 위치는 실제 시설 좌표다. 일반 지도는 화면 거리 44px를 기준으로 묶고, 원형 터치 영역은 44px다. 방문 계획은 동좌표만 묶어 기존 방문 순번을 유지하며 경로선·완료·다음 방문지 정보를 바꾸지 않는다.
- 종류·상태·범례 변경 시 이전 카드를 닫고 현재 검색어·내 주변 의도에 맞춰 결과를 갱신한다. 지도 교체·다음 선택·검색 입력·닫기·내 주변 전환 시 이전 선택을 취소한다. 다른 지도로 늦게 도착한 검색이나 입력은 반영하지 않는다.
- 진행 방향을 위로 보는 순찰 지도에서 부모 지도와 자동차의 회전을 정확히 상쇄한다. 359°→1° 전환도 누적 회전값을 사용한다.
- 밝기 검토의 조명 범위 원은 모델과 같이 분전함 추정 좌표 시설을 제외한다. 추정 시설 자료 자체를 삭제하지 않으며 기존 후보·현장 관찰은 유지한다.

시설·작업·점검·주민 접수 payload와 Firebase 설정·규칙·Functions는 바꾸지 않았다. 별도 개발 중인 v61 유지보수 기능은 이번 지도 배포에 포함하지 않는다.

## 확인

기존 구현에서 동좌표 목록 부재, 순찰 합성 방향, 추정 좌표 범위 원을 각각 먼저 실패시켰다. 이후 독립 배포본의 Node 검사 415개가 통과했다. 새 마커 브라우저 검사는 실제 Leaflet과 공개 대장 좌표를 사용해 39시설의 터치·키보드 선택, 지도 원본 불변, 필터·검색·내 주변·지도 교체, 상세 왕복의 위치·선택 복원, 방문 순번을 확인한다.

순찰 단위 6개와 실제 DOM 회전 24조합, 359°→1°의 전환 중간 프레임을 확인했다. 추정 좌표 검사는 실제 `openReviewMap()`을 실행해 전체·개별 지도, 동·거리 조건, 후보·관찰 유지, 원본 불변과 보정 후 재표시를 확인한다. 관련 기존 지도·방문 계획·순찰·조명 검토·내비게이션 검사도 실행한다.

브라우저 회귀는 Firebase를 비활성화한 독립 체험 환경과 제어한 영상·센서를 사용한다. 실제 운영 직원 인증·주행 중 GPS·나침반·장시간 현장 성능을 검증한 결과는 아니다. Pages 파이프라인은 앱·서버/권한 규칙과 브라우저 39종을 모두 통과한 공개 파일만 게시한다.

기존 앱 사용자는 미전송 기록·초안을 확인한 뒤 **새 버전 적용**을 실행한다.
