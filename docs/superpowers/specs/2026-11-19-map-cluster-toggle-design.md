# 지도보기 묶어 보기 켜기·끄기 (v85)

## 왜
직원이 시설을 좌표 그대로 보고 실제로 어떻게 퍼져 있는지 한눈에 파악하고 싶을 때가 있다. 지금은 숫자 버블로 묶여 있어서 그 분포가 보이지 않는다.

## 목표
- 지도보기에 "묶어 보기" 켜기·끄기 버튼을 둔다. 기본값은 켜짐(지금과 같음)이다.
- 끄면 화면 안의 모든 시설을 실제 좌표에 점으로 그린다. 축소했을 때의 숫자 버블(`mapcl`)과 겹침 묶음(`mapstack`)을 둘 다 쓰지 않는다.
- 끈 상태에서도 겹친 시설을 고를 수 있어야 한다. 누른 자리의 24px(`MAP_TAP_PX`) 안에 보이는 시설이 2개 이상이면 기존 "가까운 시설 N개" 목록(`showMapGroup`)을 열고, 1개면 시설 카드를 연다.
- 설정은 기기에 기억한다(`localStorage` `dg_mapCluster`). 순찰 지도의 `dg_ptHeadUp`과 같은 방식이다. 저장값을 읽지 못하면 켜짐으로 시작하고, 쓰지 못하면 현재 화면에서만 변경을 적용한다.

## 하지 않는 것
- 방문 계획 지도(`GM.route`)는 바꾸지 않는다. 이미 실제 위치에 번호로 그리고 있다.
- 마커 모양·크기 규칙, 표찰 번호 라벨 규칙(줌 18 이상)은 바꾸지 않는다.

## 실패로 볼 것
- 끈 상태에서 겹친 시설 중 하나를 고를 수 없다.
- 켠 상태의 동작이 지금과 달라진다.

## 방법 비교
- **A. 버튼 하나로 두 종류 묶음을 모두 끄기 (선택)**: 좌표 분포를 보려는 목적에 맞다. 대신 구 전체를 볼 때 점 수천 개(전체 8,379개)를 Canvas로 그리므로, 저사양 휴대폰에서는 지도를 움직일 때 느려질 수 있다.
- B. 축소했을 때의 버블만 끄기: 만들기는 더 간단하지만, 확대해도 붙어 있는 등이 계속 묶여 보여서 목적에 절반만 맞는다.

사용자가 A를 골랐다(2026-11-19).

## 구현하는 쪽에서 정할 것
- 버튼 위치: 지도 아래 범례 줄(`#mapLegend`) 끝에 둔다. `aria-pressed`를 쓰고, 누르면 "묶어 보기를 껐어요"처럼 토스트로 알린다. (구현 측 결정)
- 버전: `v85-map-cluster-toggle`. `sw.js`의 VERSION, `APP_VER`, RELEASE_NOTES를 함께 올린다.
