# v63 위성지도 배포 검증

운영 기준 `d0734dd7b9c414aa5108743d1f81325b45bc61fd`(v60) 위에 지도 개선만 반영한 배포본이다. 전체 개발본과 분리한 `release/v63-vworld` 작업 공간에서 검사한다.

## 배포 범위

- 일반 지도, 위성·항공사진, 사진＋도로명 전환과 브라우저별 마지막 선택 기억.
- 사용자가 제공한 VWorld 개발키 연결. 실제 키 값은 이 문서나 검사 로그에 기록하지 않는다. 브라우저에 전달되는 공개 지도 키이며 도메인·서비스·한도는 발급 계정에서 관리한다.
- 위치·확대·시설·GPS·순찰 경로를 유지하고, 영상 오류 시 일반 지도로 복귀한다.
- 영상의 원색을 유지하며 타일을 서비스 워커나 출동 자료에 보관하지 않는다.
- 앱과 서비스 워커 버전은 모두 `v63-vworld`다. 기존 사용자는 미전송 기록과 초안을 확인한 뒤 **새 버전 적용**을 실행한다.

Firebase·주민 접수 설정, 업무 저장 코드, 대장, Firestore 규칙·인덱스, Functions는 운영 기준과 동일하다. 별도 v61 유지보수 기능은 새 규칙이 필요해 이번 Pages 배포에 포함하지 않는다. Firebase 규칙이나 서버를 배포한 것으로 해석하지 않는다.

## 로컬 검사

- 독립 작업 공간의 기준 v60 코드 검사: 393/393 통과.
- 지도 적용 후 `node scripts/check.mjs`: 406/406 통과. 지도 컨트롤러 9개와 PWA·서비스 워커 15개 검사를 포함한다.
- 실제 VWorld 로컬 앱 검사: Satellite 30건, Hybrid 15건을 정상 이미지로 수신했다. 두 영상 모드에서 지도 위치·확대·시설 표시가 유지됐고 브라우저 오류는 없었다. Firebase를 비활성화한 체험 환경이며 운영 자료를 쓰지 않았다.
- 독립 코드 검토: v61 모듈 참조 없이 필수 앱 자산이 서비스 워커에 포함되고, 직원 앱의 변경이 지도·버전 안내 범위인지 확인했다.

전체 브라우저 검사와 원격 배포 결과는 아래 절차로 확인한다. 로컬 기록은 `D:\Temp\streetlight-v63-release-check.log`, `D:\Temp\streetlight-v63-release-browser\results.json`, `D:\Temp\streetlight-v63-release-live\browser-results.json`에 보관한다.

## 원격 반영 확인

[Pages 배포 workflow](https://github.com/lanian/donggu-streetlight/actions/workflows/pages.yml)는 앱·서버·규칙 검사와 전체 브라우저 검사가 모두 성공한 커밋의 공개 앱 파일만 게시한다. 배포 후 공개 URL의 앱·서비스 워커·지도 모듈 버전과 파일 내용을 대조하고, 공개 자산을 사용하는 체험 환경에서 실제 영상 표시를 별도로 확인한다.

이 검사는 실제 직원 계정의 인증·운영 데이터 저장, 현장 센서, 영상 전체 지역의 품질·촬영 시점, 키 만료·할당량 동작까지 증명하지 않는다.
