## 공개 배포 확인

파이프라인 `42454438802`는 앱·서버/Firestore 규칙 검사·브라우저 45개 스크립트·Pages 게시를 모두 통과했다. 2026-11-08 15:28 KST 이후 검증에서 공개 파일 6개의 SHA-256이 커밋 Git blob과 일치했다. 실제 브라우저가 읽은 UI 자산 5개도 일치했다.

공개 앱을 새 브라우저 컨텍스트에서 열고 Firebase 설정을 null로 대체한 체험 저장소임을 확인했다. 외부 호스트·서비스워커·비조회 요청을 차단한 상태에서 합성 다각형만 생성했다. 실제 운영 저장소와 실제 제외 범위를 수정하지 않았다.

`hasTouch: true` Chromium에서 실제 touchscreen tap으로 4점 그리기·번호점 선택·선의 중간점 삽입을 확인했다. 그리기 마치기 후 지도 바탕을 눌러도 점이 추가되지 않았다. 실제 마우스 드래그·선택점 삭제·undo/redo는 나머지 점의 순서를 보존했다.

체험 저장소에 두 번 저장한 결과 revision 1·2, 기존 polygon payload와 최초 불변 변경 영수증이 유지됐다. 편집 모드·선택·undo 이력은 payload에 들어가지 않았다. 브라우저 오류·SDK·비조회 HTTP 요청·실제 GPS는 모두 0이었다.

390/1280px·light/dark의 지도 화면과 전체 편집 화면 8장을 저장했다. 캡처는 sticky 헤더 아래에 지도를 정렬하고 `#sheet`만 촬영했다. 전체 편집 캡처는 내용 확인용 높은 viewport이고 지도 캡처는 높이 844px이다. 지도 타일은 격리한 합성 이미지다. 첫 캡처 시도의 sticky 헤더 정렬 검증은 촬영 절차를 고친 뒤 통과했으며 제품 코드는 추가 변경하지 않았다.
