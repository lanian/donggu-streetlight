## 배포 전 검증

- 공개 배포 후보 Node 473개와 v61 포함 개발 폴더 Node 561개 통과.

- 공식 URL 제한, QR의 정확한 시설 확정·오래된 표시번호 정정, 누락·철거·중복 ID 방어, 복사 성공·거부·입력 유지, 개인정보·위치·사진·자체 전송 차단을 검증했다.

- 독립 검토에서 찾은 번호 수정 시 보이는 표찰과 메모 값 불일치, 긴 QR 표찰의 가로 넘침, details 내부 textarea 경계 문제를 RED로 재현한 뒤 수정했다.

실제 Firebase·공식 운영서비스 접수는 실행하지 않았다. 브라우저의 gateway·문자·이메일·공식 이동 대상은 합성 자료와 차단된 외부 요청으로 검증했다.
