# 실제 휴대폰 확인 목록 (v74~v79)

v74~v79 변경은 시험용 브라우저에서만 확인했다. 아래 순서대로 실제 휴대폰에서 한 번씩 써 보고, 각 항목에 **정상 / 이상**과 기기(예: 갤럭시 S23 · 크롬)를 적는다. 이상하면 화면을 캡처해 둔다. 전체 10~15분 정도 걸린다.

## 0. 준비

- [ ] 화면 맨 아래 **"버전 v79"** 가 보이는지 확인한다. 이전 버전이면 "새 버전 있음"을 눌러 업데이트하거나 앱을 완전히 닫았다 다시 연다.
- 관리자 계정 1개가 필요하다. 6번은 담당자 계정 1개가 더 있어야 한다.

## 1. 지도 가까운 시설 목록 스크롤 (v78)

1. **현장 점검** 탭 → **지도(현재 목록)**.
2. 숫자가 적힌 동그라미(겹친 시설 묶음) 중 **숫자가 6 이상**인 것을 누른다. 안 보이면 지도를 더 확대한다.
3. "가까운 시설 N개" 목록을 손가락으로 위로 끈다.

- [ ] 목록이 스크롤되고, 아래 지도는 움직이지 않는다.
- [ ] 목록의 시설을 누르면 그 시설 카드가 열린다.

## 2. "내 위치" 두 번 누르기 (v79)

1. 같은 지도에서 **내 위치**를 빠르게 두 번 누른다.

- [ ] 지도가 확대되지 않는다(축척 그대로).
- [ ] 버튼 글자가 "따라가는 중" → "내 위치"로 돌아온다.

## 3. 약한 신호에서 출동 자료 (v77)

1. 연결된 상태에서 **관리 현황 → 출동 자료 준비 → 준비할 작업 조회 → 선택 작업 자료 받기**를 누른다. "준비 완료"가 나올 때까지 기다린다(내 담당 미완료 작업이 있어야 한다).
2. **인터넷이 안 되는 Wi-Fi**에 연결한다. 예: 모바일 데이터를 끈 다른 폰의 핫스팟.
3. **관리 현황 → 보수 작업**을 연다.

- [ ] 8초쯤 뒤 "연결이 느려…" 안내가 나오거나, 연결 실패 안내 아래에 **"출동 자료 · 시각에 받은 사본"** 묶음이 보인다.
- [ ] 묶음의 작업을 누르면 바로 작업 상세가 열리고, "출동 준비자료" 안내가 보인다.
- 비행기 모드에서는 기기에 남은 목록이 대신 보일 수 있다. 이 경우 정상이다.

## 4. 방문 계획 지도에서 순서 바꾸기 (v75)

1. **관리 현황 → 미점검·방문 계획**에서 시설을 3곳 이상 골라 방문 계획을 만든다.
2. **계획 지도**를 열고 번호 마커를 누른다.

- [ ] 카드에 "다음 방문지로 · 한 칸 앞 · 한 칸 뒤" 버튼이 보이고, 누르면 번호가 바뀐다.
- [ ] 지도를 닫으면 계획 목록의 순서도 같게 바뀌어 있다.
- [ ] 이미 완료한 방문지에는 순서 버튼이 없다.

## 5. 시설 화면의 분전함·회로 (v76)

1. 분전함·회로가 연결된 시설을 연다.

- [ ] "분전함·회로와 부품 이력"이 이전처럼 보인다. 처음 열 때 눈에 띄게 늦지 않다.

## 6. 현장 완료 입력 보존 (v74, 계정 2개)

1. 담당자 폰: 배정된 작업을 열고 조치 내용을 입력한다. **저장하지 않는다.**
2. 관리자 폰: 같은 작업의 **작업 정보 수정**에서 완료 기한을 바꿔 저장한다.
3. 담당자 폰: 작업을 다시 연다.

- [ ] 입력해 둔 조치 내용이 남아 있고, 변경을 알리는 안내가 보인다.

## 7. 검수 대기 작업의 담당자 변경 (v74)

1. 관리자: 검수 대기 상태 작업 → **작업 정보 수정**.

- [ ] 담당자 선택이 잠겨 있고, "보완 요청 후 변경" 안내가 보인다.

## 8. 기기에 따라 다른 것 (가능하면)

- [ ] **보고서 → 인쇄/PDF**: 저장되는 PDF 파일 이름이 보고서 제목인지, 인쇄 뒤 앱 화면 제목이 원래대로 돌아오는지.
- [ ] **지도 카드 → 길찾기**: 카카오맵 앱이 없는 폰에서 눌렀을 때 웹 지도나 안내로 넘어가는지.
- [ ] **아이폰(사파리)**: 1~3번을 한 번 더.
