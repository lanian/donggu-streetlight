# 실제 휴대폰 확인 목록 (v74~v85)

v74~v85 변경은 시험용 브라우저에서만 확인했다. v80(운영 시스템 연계 기본 기간)은 기기 시간대가 한국이 아닐 때만 생기던 문제라 국내 휴대폰 확인 항목이 없다. v83(계정이 바뀌는 짧은 사이의 계획 저장)은 사람이 손으로 맞추기 어려운 순간이라 시험으로만 확인한다. v84의 업무 현황 한국 시간 집계도 기기 시간대가 한국이 아닐 때만 달라지던 부분이라 확인 항목이 없다. 아래 순서대로 실제 휴대폰에서 한 번씩 써 보고, 각 항목에 **정상 / 이상**과 기기(예: 갤럭시 S23 · 크롬)를 적는다. 이상하면 화면을 캡처해 둔다. 전체 15~20분 정도 걸린다.

## 0. 준비

- [ ] 화면 맨 아래 **"버전 v85"**가 보이는지 확인한다. 이전 버전이면 "새 버전 있음"을 눌러 업데이트하거나 앱을 완전히 닫았다 다시 연다.
- 관리자 계정 1개가 필요하다. 6번은 담당자 계정 1개가 더 있어야 한다.

## 1. 지도 가까운 시설 목록 스크롤 (v78)

1. **현장 점검** 탭 → **지도(현재 목록)**.
2. 숫자가 적힌 동그라미(겹친 시설 묶음) 중 **숫자가 6 이상**인 것을 누른다. 안 보이면 지도를 더 확대한다.
3. "가까운 시설 N개" 목록을 손가락으로 위로 끈다.

- [ ] 목록이 스크롤되고, 아래 지도는 움직이지 않는다.
- [ ] 목록의 시설을 누르면 그 시설 카드가 열린다.

## 1-1. 지도 묶어 보기 켜기·끄기 (v85)

1. **관리 현황 → 위치 분포 → 지도에서 보기**에서 구 전체 지도를 연다. 범례의 **묶어 보기**를 끄고 지도를 움직이거나 확대·축소한다.
2. 확대해서 가까이 붙은 시설 점을 누른 다음, 목록에서 시설 하나를 고른다.
3. 지도를 닫았다 다시 열어 설정을 확인한다. **묶어 보기**를 켜고 구 전체가 보이도록 축소한다.

- [ ] 끄면 숫자 묶음이 점으로 바뀌고, 겹친 점을 누르면 **가까운 시설** 목록에서 원하는 시설 카드를 열 수 있다.
- [ ] 다시 열어도 설정이 유지되고, 켜면 숫자 묶음이 돌아온다.
- [ ] 구 전체에서 끈 상태로 이동·확대·축소할 때 점이 계속 표시된다. 느리거나 화면이 멈추면 기기와 브라우저를 함께 기록한다.

## 2. "내 위치" 두 번 누르기 (v79)

1. 같은 지도에서 **내 위치**를 빠르게 두 번 누른다.

- [ ] 지도가 확대되지 않는다(축척 그대로).
- [ ] 버튼 글자가 "따라가는 중" → "내 위치"로 돌아온다.

## 3. 약한 신호에서 출동 자료 (v77)

1. 연결된 상태에서 **관리 현황 → 출동 자료 준비 → 준비할 작업 조회 → 선택 작업 자료 받기**를 누른다. "준비 완료"가 나올 때까지 기다린다(내 담당 미완료 작업이 있어야 한다).
2. **인터넷이 안 되는 Wi-Fi**에 연결한다. 예: 모바일 데이터를 끈 다른 폰의 핫스팟.
3. **관리 현황 → 보수 작업**을 연다.

- [ ] 8초쯤 뒤 "연결이 느려…" 안내가 나오거나, 연결 실패 안내 아래에 **"출동 자료 · 시각에 받은 사본"** 묶음이 보인다.
- [ ] 묶음의 작업을 누르면 바로 작업 상세가 열리고, "출동 준비자료" 안내가 보인다.
- [ ] (v81) 정상 연결로 돌아온 뒤 다른 화면에 갔다가 뒤로 가기로 그 작업에 돌아오면, "출동 준비자료" 안내 없이 최신 내용이 보인다.
- 비행기 모드에서는 기기에 남은 목록이 대신 보일 수 있다. 이 경우 정상이다.

## 4. 방문 계획 지도에서 순서 바꾸기 (v75)

1. **관리 현황 → 미점검·방문 계획**에서 시설을 3곳 이상 골라 방문 계획을 만든다.
2. **계획 지도**를 열고 번호 마커를 누른다.

- [ ] 카드에 "다음 방문지로 · 한 칸 앞 · 한 칸 뒤" 버튼이 보이고, 누르면 번호가 바뀐다.
- [ ] 지도를 닫으면 계획 목록의 순서도 같게 바뀌어 있다.
- [ ] 이미 완료한 방문지에는 순서 버튼이 없다.

## 4-1. 두 창에서 방문 계획 고치기 (v82)

1. 4번의 방문 계획이 있는 상태에서, 같은 폰의 브라우저로 앱을 **새 탭(창)으로 하나 더** 연다. 두 창 모두 **관리 현황 → 미점검·방문 계획**을 연다.
2. 첫째 창: 다음 방문지 카드의 **방문 완료**를 누른다.
3. 둘째 창(새로 고치지 않은 채): 목록에서 아직 안 간 방문지의 **아래로**를 누른다.

- [ ] 둘째 창에 "다른 탭에서 방문 계획이 바뀌어 최신 계획을 불러왔어요. 다시 해 주세요." 안내가 나오고, 첫째 창에서 완료한 방문지가 완료로 보인다.
- [ ] 둘째 창에서 **아래로**를 다시 누르면 순서가 바뀌고, 첫째 창을 새로 고쳐도 방문 완료가 남아 있다.
- [ ] 한 창에서 **아래로**를 빠르게 두 번 눌러도 "다른 탭" 안내가 나오지 않는다.

## 4-2. 계획을 지우고 다시 만든 뒤 옛 창 (v84)

1. 4-1처럼 같은 폰에서 앱을 두 창으로 열고, 두 창 모두 같은 방문 계획이 보이는 **관리 현황 → 미점검·방문 계획**을 연다.
2. 첫째 창: **계획 지우기 → 지우기**를 누른 뒤, 앞과 다른 시설을 골라 **새 방문 계획**을 만든다.
3. 둘째 창(새로 고치지 않아 옛 계획이 보이는 채): 다음 방문지 카드의 **방문 완료**를 누른다.

- [ ] 둘째 창에 "다른 탭에서 방문 계획이 바뀌어 최신 계획을 불러왔어요. 다시 해 주세요." 안내가 나오고, 첫째 창에서 새로 만든 계획이 보인다.
- [ ] 첫째 창을 새로 고쳐도 새 계획이 그대로 있고, 둘째 창에서 누른 방문 완료가 새 계획에 들어가 있지 않다.

## 5. 시설 화면의 분전함·회로 (v76)

1. 분전함·회로가 연결된 시설을 연다.

- [ ] "분전함·회로와 부품 이력"이 이전처럼 보인다. 처음 열 때 눈에 띄게 늦지 않다.

## 5-1. 분전함·회로 다시 조회 (v81)

1. **인터넷이 안 되는 Wi-Fi**에 연결한 채, 분전함·회로가 연결된 시설 중 출동 자료로 받지 않은 시설을 연다.
2. "분전함·회로와 부품 이력"에 조회 실패 안내가 보이면, 정상 연결로 돌아와 같은 시설을 다시 연다.

- [ ] 다시 열면 실패 안내 대신 분전함·회로 이름이 보인다.

## 6. 현장 완료 입력 보존 (v74, 계정 2개)

1. 담당자 폰: 배정된 작업을 열고 조치 내용을 입력한다. **저장하지 않는다.**
2. 관리자 폰: 같은 작업의 **작업 정보 수정**에서 완료 기한을 바꿔 저장한다.
3. 담당자 폰: 작업을 다시 연다.

- [ ] 입력해 둔 조치 내용이 남아 있고, 변경을 알리는 안내가 보인다.

## 7. 검수 대기 작업의 담당자 변경 (v74)

1. 관리자: 검수 대기 상태 작업 → **작업 정보 수정**.

- [ ] 담당자 선택이 잠겨 있고, "보완 요청 후 변경" 안내가 보인다.

## 7-1. 업무 현황 CSV 회로 열 이름 (v84)

1. **관리 현황 → 업무 현황**에서 고장 점검 기록이 있는 기간으로 **기간 조회**를 누른다.
2. **CSV**를 눌러 파일을 저장하고 엑셀·구글 시트 등으로 연다.

- [ ] 회로별 고장 기록 묶음의 제목 행이 "확인된 회로", "고장 점검"이고, "점멸기"로 나오지 않는다. 화면 표의 열 이름과 같다.

## 8. 기기에 따라 다른 것 (가능하면)

- [ ] **보고서 → 인쇄/PDF**: 저장되는 PDF 파일 이름이 보고서 제목인지, 인쇄 뒤 앱 화면 제목이 원래대로 돌아오는지.
- [ ] **지도 카드 → 길찾기**: 카카오맵 앱이 없는 폰에서 눌렀을 때 웹 지도나 안내로 넘어가는지.
- [ ] **아이폰(사파리)**: 1~3번을 한 번 더.
