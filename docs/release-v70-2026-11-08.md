# v70 운영 신고 파일 검토 준비 화면 공개

`v70-report-import`는 로컬에서 구현한 신고 반입 준비 기능을 공개 앱에 반영한다. 담당 부서 협의 전의 준비 화면이며 실제 운영서비스 자동 수집·운영 저장소 반입을 활성화하지 않는다.

## 제공 범위

- **관리 현황 → 운영 시스템 연계 → 운영 신고 파일 검토**에서 준비 양식과 기능 범위를 확인한다.
- 관리자 체험 모드에서는 CSV/JSON 준비 양식·합성 예제·신규/중복·유일 시설 연결 검토와 선택한 신규 신고의 로컬 반입을 시험할 수 있다.
- 실제 저장소에서는 파일 선택·검토·적용을 비활성화한다. 강제 호출도 읽기 이전의 local 계정·local DB·Firebase 없음·관리자·쓰기 권한 검사에서 거절한다.
- 이름·연락처·사진·GPS·자유문 원본 등의 추가 필드를 반입하지 않는다. 기존 신고·업무·처리 상태를 덮지 않는다. 원본 종결·취소와 충돌·미연결·중복 시설은 적용에서 제외한다.
- 운영 API·자동 로그인·신고 큐를 만들지 않는다. 동의·권한·반출 형식은 담당 부서 및 운영 업체 협의 뒤 별도 연결 작업으로 확인한다.

변경의 본체는 [로컬 구현 기록](implementation-official-report-import-prep-2026-11-08.md)의 `36c9d59`와 같다. 공개 반영에서는 버전·설명·서비스워커 캐시를 갱신한다. Firebase·주민 설정·지도 설정·규칙·Functions는 변경하지 않는다. 별도 v61 개발분은 기본 폴더에 보존한다.

## 검증 범위

순수 코어/로컬 실행기 19개와 브라우저 15개를 포함하는 전체 Node·기존 연계·버전 회귀를 확인한다. 배포 파이프라인은 전체 브라우저 46개 스크립트와 앱·서버/규칙 검증을 거친다. 게시 후 공개 자산 해시·체험 반입·재반입·개인정보 제외·운영 환경 강제 호출 차단을 Firebase와 외부 호스트를 격리한 브라우저에서 재확인한다.

실제 운영서비스의 데이터 조회·개인정보 반출 허용·실제 Firebase 저장·업체 API/반출 파일 호환을 검증한 결과는 아니다. 새로 허용한 범위는 준비 화면의 공개 반영이다. 운영 연결은 계속 차단한다.
