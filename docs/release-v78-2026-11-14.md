# v78 지도 가까운 시설 목록 스크롤 수정

앱 버전은 `v78-map-list-scroll`이다. Firestore 규칙·Functions·데이터 형식은 바꾸지 않으며 앱 공개만으로 반영된다.

## 문제

지도에서 겹친 시설 묶음(숫자 표시)을 누르면 나오는 "가까운 시설 N개" 목록이 손가락으로 스크롤되지 않았다. 목록을 끌면 목록 대신 아래의 지도가 움직였고, 마우스 휠은 목록 대신 지도를 확대·축소했다. 목록이 260px 높이에서 잘려 아래쪽 시설을 고를 수 없었다(직원 보고).

## 원인

시설 카드(`#mapCard`)는 Leaflet 지도 컨테이너(`#gmap`) 안에 있다. 카드에서 시작한 터치·휠 이벤트가 지도까지 전달되어, Leaflet의 지도 끌기(이동 중 `preventDefault`)와 휠 확대가 목록 스크롤보다 먼저 처리됐다.

## 수정

지도를 만들 때 카드에 Leaflet의 `L.DomEvent.disableClickPropagation`·`disableScrollPropagation`을 적용했다. 지도 위 컨트롤에 쓰는 표준 방식이다. 카드의 `mousedown·touchstart·dblclick·contextmenu·wheel`만 지도로 전달되지 않고, `click`은 그대로 문서까지 전달되어 기존 버튼 처리는 같다.

## 검증

- 실제 Chromium 터치 입력(CDP `Input.dispatchTouchEvent`)으로 재현: 수정 전 목록 `scrollTop` 0·지도 중심 이동, 수정 후 목록 135px 스크롤·지도 고정. 같은 방법으로 지도 밖의 대조 스크롤 상자가 스크롤되는 것을 확인해 시험 방법이 유효함을 확인했다.
- `scripts/marker-selection-browser-smoke.cjs`에 터치 스크롤 단언을 추가했다. 수정 전 실패, 수정 후 통과. 같은 파일의 탭·키보드 선택 시나리오도 통과한다.
- 마우스 휠은 이 헤드리스 환경에서 대조 상자도 스크롤되지 않아 스크롤 자체는 확인하지 못했다. 카드 위 휠로 지도가 확대·축소되지 않는 것(확대 19 유지)만 확인했다.
- 실제 휴대폰 확인은 아니다.
