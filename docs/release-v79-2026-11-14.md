# v79 지도 "내 위치" 버튼 두 번 누름 확대 수정

앱 버전은 `v79-map-loc-double-tap`이다. Firestore 규칙·Functions·데이터 형식은 바꾸지 않으며 앱 공개만으로 반영된다.

## 배경

v78에서 지도 안의 시설 카드가 터치를 지도에 빼앗기던 문제를 고친 뒤, 앱의 다른 Leaflet 지도에도 같은 구조가 있는지 점검했다.

| 지도 | 지도 안의 요소 | 결과 |
|---|---|---|
| 지도 화면(`#gmap`) | 시설 카드, "내 위치" 버튼 | 카드는 v78에서 수정. **"내 위치" 버튼은 문제 있음** |
| 위치 고르기(`#posMap`), 미등록 등 위치(`#regMapPick`), 위치 수정(`#leMapBox`) | 없음 | 해당 없음 |
| 순찰 지도(`#ptMapBox`) | 지도는 안쪽 `#ptMapRot`에 만들어지고, 버튼은 그 바깥 | 해당 없음 |
| 순찰 경로 지도(`openPatrolMap`) | 없음 | 해당 없음 |

## 문제와 원인

"내 위치"는 한 번 누르면 따라가기를 켜고, 다시 누르면 끈다. 빠르게 두 번 누르면 버튼이 지도 컨테이너 안에 있어 Leaflet이 이를 지도의 두 번 누름으로 받아 한 단계 확대했다. 실제 Chromium에서 마우스 더블클릭(16→17)과 터치 두 번 누름(17→18) 모두 재현했다.

## 수정

지도를 만들 때 버튼에도 `L.DomEvent.disableClickPropagation`을 적용했다. `click`은 그대로 전달되므로 한 번 누름 동작은 같다.

## 검증

- `scripts/marker-selection-browser-smoke.cjs`에 확대 16에서 더블클릭·터치 두 번 누름 후 확대 단계가 그대로인지 단언을 추가했다. 수정 전 실패, 수정 후 통과.
- 처음 작성한 단언은 확대 19(최대)에서 실행되어 수정 전에도 통과했다. 확대 16에서 시작하도록 고쳐 실패를 확인했다.
- "내 위치"를 누르는 기존 검사(`map-view`, `pc-location` 등)를 포함한 지도·위치 관련 브라우저 검사 11종 통과.
- 실제 휴대폰 확인은 아니다.
