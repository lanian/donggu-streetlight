# v69 다각형 구역을 지도에서 편하게 편집

`v69-polygon-editor`는 밝기 검토 제외 구역·보행로 예외의 다각형 입력을 개선한다. 저장 형식과 최종 형상 검증은 유지하며 새 기능은 편집 화면에만 적용한다.

## 바뀐 동작

- 지도를 범위 선택 바로 아래에 배치하고 좌표 입력은 **좌표 직접 입력 · 고급 설정**으로 접었다.
- **점 추가**에서 경계를 찍고 **그리기 마치기 · 모양 수정**으로 전환한다. 수정 모드의 지도 바탕 클릭은 점을 추가하지 않는다. 기존 경계는 수정 모드로 열린다.
- 번호 점을 끌어 이동하거나 선택 후 삭제한다. 선의 **+**로 중간 점을 넣는다. 점은 44px 대상이며 키보드 선택·방향키 이동·Delete 삭제를 지원한다.
- **되돌리기·다시하기**는 점 추가·이동·삭제·중간점·수동 좌표 입력·전체 비우기와 선택점을 최대 50단계 복구한다. 전체 비우기는 먼저 확인한다. 이력은 현재 초안 객체의 메모리에서 유지하며 새로고침 후에는 저장된 좌표로 시작한다.
- 겹치는 점·자기 교차·3점 미만 등의 상태는 수정할 수 있게 유지하되 저장과 그리기 마치기를 비활성화한다. 최대 32점 제한과 기존 형상 검증을 유지한다.
- 저장 중·읽기 전용·권한 상실·다른 탭 충돌·이전 화면의 늦은 지도 이벤트를 차단한다. 초안 충돌은 입력과 지도를 잠그고 현재 입력의 새 구역 복사 또는 최신 초안 열기를 제공한다.

원형 구역, 구역 적용·해제, 검토 범위·보행로 예외·현장 근거, 저장 payload·영수증·CAS·보관 정책과 운영 설정은 유지한다. 점 편집 helper와 전용 CSS를 서비스워커 필수 자산에 추가했다. Firebase·Functions·Firestore 규칙·지도 공급자 설정은 바꾸지 않는다.

## 검증

새 helper 단위 15개와 지도 편집 Chromium 시나리오 15개를 추가했다. 미구현 UI·직접 입력한 잘못된 좌표의 되돌리기 실패·충돌 후 편집 잠금 누락을 RED로 재현하고 수정했다. 실제 포인터 드래그, 경계 순서·중간점·선택 삭제·그리기 완료·undo/redo, 잘못된 원문 보존·자기 교차·32점, 초안 복구·기존 payload·권한·저장 중·이전 콜백·읽기 전용을 검증한다.

기존 구역 브라우저 10개는 원형·예외·재접속·불변 영수증·전송 지연·저장 실패·두 탭 충돌과 명시적 복사를 유지한다. 390/1280px 주간·야간에서 지도·도구·고급 좌표 경계와 44px 대상을 확인한다. 외부 요청·Firebase·서비스워커를 격리한 합성 환경이며 실제 운영 데이터를 수정하지 않는다. 전체 CI와 공개 배포 확인은 기본 폴더의 배포 기록에 남긴다.

공개 후보 Node 488개, 기존 v61 개발분을 보존한 기본 폴더 Node 576개, 신규 지도 편집 15개와 기존 구역 10개 브라우저 시나리오가 두 폴더에서 통과했다. 두 전체 검사를 동시에 실행한 중간 검증에서는 변경하지 않은 사진 묶음의 25ms 타임아웃 기대 검사가 한 번 실패했다. 해당 파일 28개 단독 검사와 공개 후보 전체 488개 단독 재검사는 통과했다. 공개 자산과 실제 편집 동작은 전체 CI 게시 뒤 별도로 확인한다.
