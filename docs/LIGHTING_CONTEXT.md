# 밝기 검토에 현장 자료 보완하기

밝기 검토는 현장 확인 순서를 정하는 참고 도구입니다. 동구 관리 대장에 없는 다른 기관의 등, 주차장 조명, 상가 조명이 실제 주변을 밝힐 수 있습니다. 대장만으로 계산한 낮은 값은 **현재 수집한 광원 자료로 설명되지 않는 지점**이며, 실제로 조명이 없거나 어둡다는 확정 판정이 아닙니다.

추가 광원과 현장 관찰을 직원이 기록하면 검토에 함께 사용합니다. 다른 기관의 대장을 자동 수집하거나 미등록 광원을 자동 발견하는 기능은 아닙니다. 시설 설치·철거나 보수 결정은 관리 주체와 현장 상태를 확인한 뒤 진행합니다.

## 서로 다른 자료를 구분하기

| 자료 | 의미 | 검토에 사용하는 방식 |
|---|---|---|
| 관리 대장 모델 | 동구 대장의 위치·종류·광원·기록된 상태로 계산한 상대 지수 | 기존 시설에서 예상하는 기여량. 실측 조도나 기준 충족률이 아님 |
| 추가 광원 | 다른 기관·상가 등에서 직접 확인한 광원의 위치, 점등 상태, 적용 범위와 시간 | 최근 야간 확인과 점등·시간 조건을 만족할 때 상대 모델에 보완. 대장 시설 수나 점검 대상을 늘리지는 않음 |
| 현장 관찰 | 특정 시각·위치에서 밝음·보통·어두움 등을 확인한 기록 | 현장 증거로 함께 표시. 상대 모델 지수에 숫자로 더하지 않음 |
| 조도계 실측 | 계측기로 측정한 lux와 기기·측정 조건 | 원래 단위로 보관. 상대 지수나 눈으로 본 밝음과 자동 환산하지 않음 |

화면의 상대 지수(예: 0.30)는 lux나 기준 충족률이 아닙니다. 휴대전화 사진의 노출과 화면 밝기도 조도 측정을 대신하지 않습니다. 실측값에는 기기와 측정 위치·방향·조건을 남기세요. **0 lux는 값이 없는 상태와 다르므로** 실제 측정한 0은 그대로 기록합니다.

## 추가 광원을 기록하는 순서

1. **밝기 예측·보완 검토 → 외부 광원 추가** 또는 **외부 광원·관찰 관리**를 엽니다. 광원의 위치와 식별할 수 있는 이름, 관리 기관 또는 시설 종류를 적습니다.
2. 실제 점등 상태와 확인 시각을 기록합니다. 야간에 확인하지 않았거나 운영 시간이 불분명하면 확인된 것처럼 입력하지 않습니다.
3. 적용 반경, 확인한 점등 시간대, 재확인 기한을 지정합니다. 반경은 도달 범위를 단순화한 값입니다. 벽·수목·고저차 뒤까지 같은 밝기라고 가정하지 않습니다.
4. 동구 대장의 같은 등이라면 해당 시설과 연결합니다. 가까이 있는 별개의 등은 구분해서 기록합니다. 같은 등을 중복 등록해 밝기를 부풀리지 않습니다.
5. 저장 완료를 확인한 뒤 같은 시간 조건으로 검토를 다시 실행합니다. 추가 광원의 보완분과 관찰 근거를 함께 확인합니다.

추가 광원은 관리 대장과 별도로 보관합니다. 다른 기관의 등을 점검 완료·동구 관리 시설로 자동 처리하거나 기존 대장 간격의 보정 표본에 넣지 않습니다. 가까운 등이나 같은 이름의 기록이 중복 가능성으로 제외되면, 현장에서 별개의 광원인지 확인한 뒤 수정합니다.

## 시간대와 재확인 기한

검토 시간은 **한국 표준시(KST, UTC+9)** 기준입니다. 선택한 시간에 상가가 닫히거나 주차장 조명이 꺼진다면, 다른 시간에 밝았다는 기록으로 그 시간의 밝기를 보장할 수 없습니다. 자정을 넘는 점등 구간도 시작·종료 시각을 확인합니다.

- 추가 광원의 유효기간 기본값은 **90일**, 관찰의 기본값은 **30일**입니다. 입력 가능한 기간은 1~365일입니다.
- 추가 광원 반경은 **5~80m**, 관찰 반경은 **5~30m**입니다. 관찰한 범위에 맞게 작게 지정합니다.
- 유효기간이 지난 기록은 이전 근거로 남지만 현재 밝기를 확정하는 데 사용하지 않습니다. 다시 방문해 확인한 시각과 조건으로 갱신합니다.
- 미래 방문 계획을 현장 확인처럼 저장하지 않습니다. 기기 시계 오차를 위한 작은 허용 범위가 있어도 미래 상황을 예측·확인한 기록으로 취급하지 않습니다.

기록의 유효기간과 **검토 대상 시간대**는 다른 조건입니다. 최근 기록이어도 선택한 시간에 꺼지는 광원은 보완에 적용하지 않습니다. 기록을 수정·삭제하거나 유효기간이 지나면 이전 계산 결과를 그대로 업무 근거로 내보내지 말고 다시 계산합니다.

## 관찰과 실측을 기록할 때

주변이 밝게 보이지만 대장 모델은 낮게 나올 때는 **현장 밝기 기록**을 남기고, 보이는 다른 광원을 별도로 확인합니다. 반대로 모델은 높아도 현장이 어둡다면 관찰을 남겨 불일치 지점으로 검토합니다. 순찰의 “등이 켜져 있음”은 해당 등 하나의 점등 확인이며 주변 구간 전체의 밝기 관찰을 대신하지 않습니다.

조도계가 없다면 관찰만 남길 수 있습니다. lux를 입력할 때는 측정 기기가 필요하며, 직접 확인하지 않은 숫자를 추정해 넣지 않습니다. 계측 시각·면·방향이 다르면 값이 달라질 수 있으므로 같은 위치의 값이라도 조건을 함께 읽습니다. 보수 작업에 입력한 실측 기록과 이 기능의 위치별 관찰은 별도 기록입니다.

### 일부 지점의 확인을 구간 전체로 넓히지 않기

예를 들어 200m 도로 중 가운데 20m만 밝게 확인했다면 나머지 180m까지 밝다고 판단하지 않습니다. 도로를 8m 이하 조각으로 나누고 광원·관찰 반경의 경계에서 다시 잘라, 적용되는 길이와 나머지 길이를 구분합니다. 도로 좌표와 입력한 반경에 따른 근사치이며 벽·수목·고저차는 모델에 포함하지 않습니다. 관찰 반경이 닿는 반대편 골목이나 벽 뒤도 현장에서 별도 확인이 필요합니다.

**전체 후보**에서는 외부 광원이나 밝음 관찰로 보완된 곳도 남겨 전후 근거를 비교합니다. **우선 현장 확인**과 **자료 부족**은 확인 순서를 좁히는 필터입니다. 지도의 전체 후보 표시는 최대 200곳이며, CSV는 선택한 보기의 전체 후보를 내보냅니다.

서로 다른 시각의 밝음·어두움 기록이 모두 유효하면 충돌이나 조건 차이를 먼저 확인합니다. 더 밝은 기록 하나로 어두움 기록을 숨기거나, 실측 하나를 주변 전체의 값으로 펼치지 않습니다. 만료·시간 미확인·중복 의심 기록도 그 사유를 보고 재확인합니다.

## 저장·권한·개인정보

이 기능의 저장은 **기기 체험 모드와 Firebase 공유 모드**에서 지원합니다. 아티팩트 저장소에서는 원자적 조건부 저장을 보장할 수 없어 실행하지 않습니다. Firebase에서는 직원 역할이 필요하며 본인 기록 또는 관리자가 허용된 기록을 수정합니다.

고정 작업 ID로 저장 결과를 확인하므로 같은 내용의 재시도는 기록을 중복 생성하지 않습니다. 그 뒤 다른 수정이 있었다면 이전 작업의 재전송으로 최신 내용을 되돌리지 않습니다. 동시에 수정된 기록은 충돌을 표시하므로 최신 내용을 다시 확인합니다. 화면의 **검토에서 제외**는 기록에 제외 표시를 남기며, 필요하면 다시 사용할 수 있습니다.

작성 중인 초안은 기록별로 보관합니다. 다른 기록을 새로 작성해도 이전 초안은 남으며 **저장 대기함 → 작성 중인 초안 → 이어 쓰기**에서 다시 엽니다. 전송 중이던 기록이 나중에 완료돼도 이후 작성한 다른 초안을 지우지 않습니다. 여러 탭에서 같은 기록을 동시에 편집하기보다는 한 탭에서 마친 뒤 최신 내용을 확인하세요.

위치·광원 종류·관리 기관·확인 조건이면 충분합니다. 주민 이름·연락처·차량번호 등 개인정보는 필요하지 않으며 메모에도 넣지 않습니다. 전용 기기와 공유 PC의 초안·대기함 복구 범위는 [업무 운영 안내](operations-guide.md)를 따릅니다. 저장 대기 중 표시는 공유 서버 반영 완료를 뜻하지 않습니다.

## 검증 범위

로컬 앱 검사는 다음 명령으로 실행합니다.

```bash
node scripts/check.mjs
```

Playwright와 Chromium을 설치한 환경에서는 별도 밝기 회귀를 실행합니다. 설치 경로 지정 방법은 [배포 안내](../deploy/README.md#로컬ci-검사)를 참고하세요.

```bash
node scripts/brightness-smoke.cjs
```

브라우저 검사는 외부 요청을 차단한 로컬 서버·독립 프로필에서 저장과 재조회, 재계산, 관찰·실측의 분리, 결과 표시를 확인합니다. 실제 다른 기관의 자료, 현장의 빛 분포, 조도계 정확도, 특정 도로의 안전·법적 적합성을 검증하는 검사는 아닙니다. 실제 Firebase 규칙 배포와 기관별 데이터 공유 협의도 별도 운영 작업입니다.

## 설명의 근거

- [FHWA — Guidelines for the Implementation of Reduced Lighting on Roadways, Ambient Luminance](https://www.fhwa.dot.gov/publications/research/safety/14050/001.cfm): 도로 주변의 밝기와 빛의 양을 별도 환경 요소로 고려한다는 설명을 참고했습니다.
- [FHWA — Roadway Lighting Workshop, Module 1](https://highways.dot.gov/sites/fhwa.dot.gov/files/Module1Workbook.pdf): 수평·수직 조도와 표면·관찰 방향에 따른 휘도 구분을 참고했습니다. 이 앱의 상대 지수와 같은 물리량으로 취급하지 않습니다.

위 자료는 개념 설명을 위한 1차 자료입니다. 이 앱의 보완 계수·반경을 공식 조명 설계식이나 국내 법적 기준으로 제시하지 않습니다.
