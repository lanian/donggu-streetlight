# 위성·항공사진 지도 · v64-map-control

일반 지도, 위성·항공사진, 사진＋도로명을 지도 안에서 전환한다. 기존 Leaflet 지도 객체를 유지하고 배경 레이어만 교체하므로 시설 표시, 위치·확대 단계, GPS, 순찰 경로와 편집 중인 도형은 그대로 남는다.

평소에는 64×44 크기의 **배경** 버튼만 표시한다. 버튼을 누르면 왼쪽에 선택창이 열리며, 선택하거나 Escape 또는 바깥을 누르면 접힌다. 선택·Escape 후에는 배경 버튼으로 포커스를 돌린다. 지도 캔버스의 첫 바깥 클릭은 선택창을 닫기만 하므로 시설 좌표나 경계점을 바꾸지 않는다. 위치 찾기 등 다른 버튼은 원래 동작을 유지한다. 오류가 있으면 작은 경고 표시와 접근성 상태 안내를 제공하며 선택창에서 사유를 확인할 수 있다.

전체 지도뿐 아니라 위치 확인·시설 좌표 편집·순찰·밝기 검토·광원·검토 구역·신고 연결 지도가 같은 기능을 사용한다. 최근 선택은 이 브라우저의 표시 설정으로 기억하며 업무 초안에 섞지 않는다. 순찰 지도 선택기는 회전판 밖에 두고, 영상 배경에는 일반 지도의 야간 색 반전을 적용하지 않는다.

실제 영상 연결 중 기존 타일의 가산 혼합 스타일이 사진을 희게 만드는 문제를 확인했다. 위성·도로명 전용 레이어에만 일반 색 혼합을 적용해 원래 색을 표시하며, 일반 지도 스타일은 유지한다. 브라우저 검사에서 수정 전 실패와 수정 후 통과를 확인했다.

## 현재 연결 상태

사용자가 제공한 브이월드 개발키를 `app/map-config.js`에 등록했다. 로컬 앱에서 실제 Satellite 항공사진과 Hybrid 도로명 타일이 표시되고, 배경 전환 시 지도 위치·확대 단계·시설 표시가 유지되는 것을 확인했다. 기본 일반 지도와 현재 Firebase·주민 접수 설정을 유지한다. 이번 배포는 v60 업무 저장 형식을 유지하는 지도 전용 버전이다. 별도 개발 중인 v61 유지보수 기능과 서버 규칙 변경은 포함하지 않는다.

키가 없거나 설정이 잘못됐으면 영상 선택이 비활성화되고 연결 준비 중으로 안내한다. 개발키의 허용 사이트·유효기간·호출 한도는 발급 계정 설정을 따른다. 로컬 확인만으로 배포 사이트의 인증과 장기 사용 가능 여부까지 보장하지 않는다.

브이월드 WMTS는 영상·하이브리드와 EPSG:3857 지도 및 Leaflet 연동을 지원한다. [공식 서비스 정보](https://www.data.go.kr/catalog/3046388/openapi.json), [VWorld 공식 WMTS 설정 예시](https://github.com/V-world/V-QGIS/blob/main/constants.py).

## 운영자가 설정할 부분

1. [브이월드](https://www.vworld.kr/)에서 사용할 사이트에 맞는 지도 API 인증키를 발급받는다. 허용 사이트·서비스와 호출 한도는 발급 계정에서 확인한다.
2. `app/map-config.js`의 `DONGGU_SATELLITE_CONFIG.apiKey`에 발급받은 공개키를 넣는다. 기존 `DONGGU_MAP_PROVIDER`와 Firebase 설정은 바꿀 필요가 없다.
3. 키 설정을 배포할 때 앱의 `APP_VER`와 서비스 워커의 `VERSION`을 동일한 새 값으로 올린다. 현재 두 값은 `v64-map-control`로 맞췄다. 사용 중인 기기는 새 버전 적용을 거쳐야 새 지도 설정을 받는다. 설정 파일만 바꾸면 기존 앱 캐시에 예전 값이 남을 수 있다.

```js
globalThis.DONGGU_SATELLITE_CONFIG = {
  apiKey: '발급받은-공개키',
  maxNativeZoom: 18,
  offlineAllowed: false
};
```

이 키는 브라우저에 전달되는 공개 지도 키다. 앱 캐시에 포함되는 설정 파일과 지도 요청 주소에서 확인할 수 있으므로 서버 비밀키를 넣지 않는다. 지도 출처 링크는 화면에 유지한다.

영상은 VWorld Satellite JPEG, 사진＋도로명은 Satellite와 투명 Hybrid PNG를 함께 사용한다. 요청 주소는 `https://api.vworld.kr/req/wmts/1.0.0/{key}/{layer}/{z}/{y}/{x}.{ext}`다. 기본 원본 타일은 18단계까지 요청하며 더 확대하면 해당 영상을 확대해 표시한다. 현재 지도의 확대 단계는 바꾸지 않는다.

## 오류와 오프라인

영상 또는 지명 레이어 한쪽에서 연속 오류가 네 번 발생하면 일반 지도로 전환하고 안내한다. 다른 레이어의 성공으로 오류 횟수를 지우지 않는다. 자동 복귀는 사용자가 마지막으로 선택한 영상 선호를 지우지 않으므로 다음 지도에서는 다시 연결을 시도할 수 있다.

닫혔거나 교체된 지도·타일의 늦은 이벤트는 무시한다. 선택기를 조작해도 시설 추가, 도형 편집, 업무 초안 저장 또는 지도 클릭으로 전달하지 않는다.

영상·지명 타일은 온라인 조회만 제공한다. 서비스 워커 타일 보관과 출동 자료에 포함하지 않으며 지역 전체 다운로드도 추가하지 않았다. 브라우저 자체 HTTP 캐시는 서버 응답 정책을 따른다.

## 검증

v64에서는 기본 접힘 크기, 열기·선택·Escape·포커스 복귀, 바깥 클릭의 좌표 편집 보호, 기존 버튼·링크 유지, 320/390/1440 화면 경계와 회전 순찰을 지도 브라우저 7개 그룹에서 확인했다. Node 검사 406개와 구역 편집·모달·순찰 지도·PC 위치 버튼 4종도 통과했다. 토글이 없는 기존 구현에서 먼저 실패를 확인한 뒤 수정했다.

지도 컨트롤러·서비스 워커 단위 검사, 실제 Leaflet 브라우저 회귀, 로컬 앱의 실제 VWorld 타일 연결을 확인했다. 브라우저 회귀는 인증키·영상 타일을 합성 자료로 대체하며, 실제 연결 확인과 구분한다. 배포용 v60 기반 독립 작업 공간의 전체 코드·브라우저·서버·규칙 검사 결과는 [v63 배포 검증 기록](release-v63-2026-11-08.md)에 기록한다.

실제 연결 검사는 광주 동구의 일부 좌표와 확대 단계에서 실시했다. 영상의 전체 지역 품질·촬영 시점, 배포 사이트의 키 만료·할당량 동작까지 보장하지 않는다. 지도 API는 온라인 조회에 사용하며 운영 데이터 변경을 위한 요청은 하지 않는다.
