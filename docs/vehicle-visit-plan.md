# 방문계획의 차량 이동 노선

`v72-vehicle-plan` 로컬 구현 기능이다. 공개 앱 반영은 별도이며 지도 API 키를 추가하지 않는다.

1. **관리 현황 → 미점검·방문 계획**에서 시설을 선택하고 방문계획을 만든다.
2. **차량 이동 노선 만들기**를 누르면 남은 시설 전체를 계획 순서대로 최대 6곳씩 나눈다. 첫 구간은 펼쳐지고 나머지 구간은 제목을 눌러 펼친다.
3. 첫 구간을 **구간 1 차량 경로 열기 → 네이버 지도 · 차량 (앱)**으로 열면 지도앱의 현재 위치를 출발점으로 사용한다. 네이버 지도앱 설치가 필요하다.
4. **내 위치 확인**으로 출발 위치를 확인하면 카카오맵 웹·앱도 선택할 수 있다. 카카오 앱은 설치가 필요하고 웹은 브라우저로 연다. ±100m 이내의 새 위치만 사용하며 5분 뒤 다시 확인한다. 위치가 거부되거나 정확하지 않으면 네이버 지도앱의 현재 위치로 열 수 있다.
5. 다음 구간은 이전 구간의 마지막 방문지에서 이어진다. 이전 구간의 도착점은 출발점으로만 다시 표시하고 새 방문지로 중복 계산하지 않는다. 한 곳만 남아도 차량 경로를 만들 수 있다.

실제 도로 경로와 운전 시간은 선택한 외부 지도에서 확인한다. 이 앱의 계획 지도·가까운 순 정렬·거리 표시는 직선 기준 방문 순서이며 자동차 최단 경로나 운전 시간으로 바꾸지 않는다. 경로를 여는 동작은 방문 완료·점검 결과·기존 계획을 저장하거나 수정하지 않는다.

완료된 시설, 철거·추정 좌표 시설은 기존 방문계획 규칙에 따라 제외한다. 시설 위치·순서·완료 상태·계정·계획이 지도 선택 도중 바뀌면 이전 링크를 열지 않으므로 최신 노선에서 다시 선택한다. 위치 확인 중 화면을 떠나면 늦은 응답으로 이전 화면을 다시 열지 않는다.

지도앱에서 실제 도로 진입과 도착점을 확인한다. 이 기능은 외부 지도 열기 전 경로 API를 호출하지 않으며 실제 앱 설치·전환·도로 결과는 기기와 지도 서비스에 따라 달라진다. 공용 단말에서는 출발 위치를 확인한 뒤 사용을 마치고 차량 노선을 접을 수 있다.

## 사용한 공식 연결 규격

- [Kakao 지도 URL](https://apis.map.kakao.com/web/guide/#routeurl): `link/by/car`, 경유 최대 5곳.
- [Kakao 앱 URL Scheme](https://apis.map.kakao.com/android_v2/docs/api-guide/urlscheme/): `by=car`, 출발점·경유점·도착점.
- [Naver 지도앱 URL Scheme](https://guide-gov.ncloud-docs.com/docs/naveropenapiv3-maps-url-scheme-url-scheme): `route/car`, 출발 생략 시 현재 위치, 경유 최대 5곳.
