# v71 접수대장 연결 준비 화면 공개

`v71-ledger-connector`는 로컬 구현 `83846d3`의 접수대장 연결 준비를 공개 앱에 반영한다. **실운영 접수대장 조회 연결은 아직 미완료**이며 공식 명세·허용 경로·인증 계약을 추정하거나 등록하지 않는다. 실제 조회 버튼과 운영 저장소 반입은 계속 비활성이다.

## 제공 범위

- **관리 현황 → 운영 시스템 연계 → 운영 신고 파일 검토 → 실운영 접수대장 연결**에서 미연결 상태와 필요한 자료를 확인한다.
- 관리자 체험 모드에서는 조회 기간을 정하고 합성 2페이지 응답을 받는다. 명시적 경로·코드·시각 변환과 전체 건수·완료·기간·반복 cursor/ID를 확인한 뒤 기존 미리보기와 체험 신고함에 연결한다.
- 중간 오류·401/403·timeout·취소·누락·범위 초과가 있으면 일부 결과를 반환하지 않는다. 기간 변경은 조회 기원의 미리보기만 비우고 기존 파일 미리보기는 유지한다.
- 최소 필드 외 개인정보 원문은 결과에 남기지 않는다. 기존 신고·완료 상태·작업을 덮지 않는다. 실제 저장소는 읽기 전 local-only 조건에서 차단한다.
- endpoint·fetch·인증·자동 로그인·실자료 조회·서버 전송 큐를 추가하지 않는다. `queryLive()`는 즉시 미설정 오류로 거절한다. 합성 명세는 운영 업체의 실제 규격이 아니다.

기능 본체는 로컬 구현과 같으며 공개 버전·설명·서비스워커 캐시만 갱신한다. Firebase·주민·지도 설정, 규칙·Functions는 변경하지 않는다. 별도 v61 개발분은 기본 폴더에 보존한다.

## 검증 범위

신규 엔진 24개와 새 Chromium 12개, 기존 파일 반입 15개와 버전 회귀를 확인한다. 앱·서버/규칙과 전체 브라우저 47개 스크립트의 배포 파이프라인을 통과한 뒤 공개 자산 해시·미연결 강제 호출·합성 전체 수신·취소·체험 반입·운영 환경 차단을 격리 브라우저에서 확인한다.

실제 업체 데이터·로그인·반출 근거·운영 Firebase 저장·공식 API/파일 호환을 검증한 결과는 아니다. 실제 연결에는 담당 부서가 허용한 범위와 공식 문서 또는 승인된 예제를 확보한 뒤 별도 어댑터/transport를 연결해야 한다. 준비 화면 공개가 해당 승인을 대신하지 않는다.
