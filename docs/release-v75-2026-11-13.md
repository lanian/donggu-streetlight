# v75 방문계획 지도에서 순서 변경

앱 버전 `v75-visit-plan-reorder`. Firestore 규칙·Functions·데이터 형식 변경은 없다. 방문계획은 기존처럼 기기에만 저장된다.

## 사용법

관리 현황 → 미점검·방문 계획 → **계획 지도**에서 아직 방문하지 않은 번호 마커를 누른다. 시설 카드에 현재 방문 순서와 버튼 3개가 나온다.

- **다음 방문지로**: 남은 방문지 중 가장 앞으로 옮긴다.
- **한 칸 앞 / 한 칸 뒤**: 바로 앞·뒤의 남은 방문지와 순서를 바꾼다.

완료(방문 체크 또는 계획 이후 점검 저장)한 방문지는 제자리에 두고 버튼을 표시하지 않는다. 바꾼 순서는 바로 저장되며 지도 번호·점선 경로, 계획 목록, 구간 거리, 차량 이동 노선(6곳 묶음)이 새 순서를 따른다. 목록의 위로/아래로와 **내 위치에서 다시 정렬**은 그대로 쓸 수 있다.

## 검증

- 순서 규칙 단위 시험 3개, 계획 저장·구간 재계산 시험 1개를 수정 전 실패 확인 후 통과시켰다. Node 전체 680개 통과.
- 방문계획 브라우저 검사에 지도 카드로 6번을 다음 방문지(3번)로 옮기고 다시 한 칸 뒤로 보내는 시나리오, 완료 방문지에 버튼이 없는 것, 목록 반영과 기기 저장을 추가했다. 지도·방문계획·차량 노선·내비게이션·다크 모드·PC 화면 검사 10종 통과.
- 390px 밝음/어두움 화면을 확인했다. 실제 현장 기기 확인은 아니다.
