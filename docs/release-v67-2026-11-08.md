# v67 비공식 현장 자료의 운영 시스템 연계

`v67-roadlighting`은 운영 시스템의 대장을 안전하게 반입하고 현장 결과를 전달용 파일로 정리하는 관리자 기능을 추가한다. 공식 API·업로드 계약이 없으므로 자동 등록이나 공식 양식 지원으로 표시하지 않는다. [사용 방법과 파일 규격](roadlighting-bridge.md)을 참고한다.

## 구현

- getPoint 원본을 브라우저에서 직접 읽는다. 안정 시설 ID·출처별 비교·미제공 필드와 현장 수정 보존·누락 자동 철거 차단을 적용했다. 다른 출처의 시설과 기존 이력·상태를 보존한다.
- 선택 기간·동·자료 종류의 점검·신고·보수·순찰과 사진을 CSV/JSON/ZIP으로 내보낸다. 전체 기록·정상 결과·긴 메모·작업 처리 이력을 보존한다. 검수 대기와 완료를 구별한다.
- 묶음·기록·사진의 해시와 안정 ID를 보존한다. 원본·미리보기 대체·누락·사진 제외를 표시하며 잘못 연결된 증빙과 중복 운영 시설번호를 차단한다. 연락처 필드는 기본 제외다.
- 기기별 연계 이력에 개별 기록의 운영 등록번호·사용자 확인·미반영 사유를 기록한다. 동일 자료 재출력은 확인 이력을 유지하며, 다른 탭의 변경은 CAS로 보호한다.
- 준비·조회·내보내기·이력 저장 중 계정·저장소·역할·화면·선택 조건 변경을 검증한다. 무응답 사진 조회는 동시 요청 수를 제한하고 대체 여부를 표시한다.

Firebase·주민 신고·지도 설정, Firestore 규칙·Functions는 변경하지 않는다. 별도 v61 개발 기능도 이 공개 배포에 포함하지 않는다. 실제 운영 시스템 접수·수정은 수행하지 않는다.

## 검증

Node·실제 앱 브라우저·ZIP 판독·독립 검토와 전체 CI를 통과한 공개 파일만 배포한다. 검증은 Firebase와 외부 요청을 차단한 합성 자료 환경이며, 운영 계정 인증·실제 등록 성공 또는 업체 파일 양식 호환을 검증한 결과와 구별한다. 구체적인 결과는 배포 기록에 남긴다.

로컬 배포 후보 Node 459개와 v61을 포함한 개발 폴더 Node 547개가 통과했다. 새 대장 브라우저 8개·연계 화면 19개 시나리오를 두 폴더에서 통과했고, 기존 업무·시설 이력·보고서 출력·PC 화면 회귀도 통과했다. 전체 브라우저 CI는 43개 스크립트다.

새 코어 회귀는 점검·사진 참조 241개, 한국어와 긴 메모, 실제 ZIP 헤더·CRC·파일 해시, 연락처 필드 기본 제외와 검수 상태를 검사한다. Python 표준 zipfile로 실제 파일도 판독했다. 사진 조회가 정지한 상태의 취소·재준비, 계정 전환, 다음 페이지 취소와 CAS 충돌을 재현해 보완했으며, 독립 규격 검토와 수정 후 품질 재검토를 통과했다.
