# 운영 신고 반입 준비 구현·검증 기록

## 최초 구현 단계

`v70-import-prep`를 구현했다. 사용자 요청에 따라 **실서비스 연결·실제 자료 반입·공개 배포·Firebase 배포·push는 수행하지 않았다.** 공개 배포용 worktree의 v69는 변경하지 않았다. 구현은 별도 `feature/official-report-import-prep` worktree와 기본 개발 폴더에 보관한다.

위 내용은 로컬 구현 커밋 `36c9d59` 당시 기록이다. 이후 사용자의 공개 반영 요청에 따른 준비 화면 배포는 [v70 반영 기록](release-v70-2026-11-08.md)을 참고한다. 운영 연결과 실제 자료 반입 차단은 유지한다.

담당 부서와 협의하기 전에 준비 양식의 공통 반입 단계를 검증하는 기능이다. 운영 업체의 실제 CSV·JSON·API와 호환된다는 의미는 아니다. 협의 후 공식 입력 어댑터와 승인된 운영 실행기·권한 규칙을 별도로 검증해야 한다. [양식·사용 방법·제한](official-report-import-prep.md)을 참고한다.

## 구현

- 순수 파서와 검토 엔진: 준비용 CSV/JSON, 2MiB·1,000행, 정해진 최소 항목, 추가 원문 제거, 엄격한 식별자·유형·시각·상태 검증.
- 시설 연결: 유일한 활성 운영 시설번호 일치만 사용. 미연결·중복 시설·종결·파일 내 내용 충돌·기존 중복을 적용에서 제외.
- 실행기: 최신 신고·시설 재검토, 안정 ID, create-if-absent와 예상 문서 없음 조건을 한 로컬 원자 저장에 적용. 기존 신고·처리 상태·보수 작업을 덮지 않는다.
- 실행 제한: 읽기 전에 local 계정·local DB·Firebase 없음·관리자·쓰기 권한을 확인한다. 화면·계정·DB·namespace·시설·선택이 바뀐 늦은 결과를 거절한다. 서버용 큐나 자동 로그인·운영 API 호출을 만들지 않는다.
- 관리자 화면: 준비 양식 내려받기·합성 예제·파일 선택·검토 표·신규 선택·체험 반입·취소·비우기. 운영 시스템 연계 화면에서 진입한다. 운영 저장소에서는 검토/적용을 비활성화한다.
- 기존 신고 스키마 12필드만 사용하고 QR 원본 관계의 `ext`는 재사용하지 않는다. 새 신고는 `접수`이며 설명은 정해진 원본 상태 문구만 넣는다. 파일·추가 개인정보·원문은 초안·기기 저장·로그에 남기지 않는다.

개발 버전·서비스워커 필수 자산·향후 CI의 새 브라우저 스크립트를 함께 등록했다. 실제 Firebase·주민 설정·지도 설정·Functions·Firestore 규칙은 변경하지 않았다. 기본 폴더의 v61 모듈은 최소 hunk 동기화로 보존했다.

## 검증

- 초기 미구현 UI와 코어 module missing을 RED로 확인한 뒤 구현했다.
- 새 코어/실행기 단위 19개 통과. 개인정보 필드 제외·유형/날짜/양식·중복·시설·종결·원자 저장·경합·운영 차단을 포함한다.
- 별도 구현 폴더 전체 Node 507개, v61 개발분을 보존한 기본 폴더 전체 Node 595개 통과.
- 새 Chromium 15개는 두 폴더에서 모두 통과했다. JSON/CSV·최소 항목·기존 원문 보존·앞자리 0·신규/중복/충돌·종결·시설·선택·재반입·오류/초과 파일·취소·화면/계정 변경·운영 환경의 강제 실행을 검증했다. 브라우저 오류와 외부 비조회 요청은 0건이다.
- 기존 운영 대장 반입·전달 ZIP·버전 정보 브라우저 회귀를 통과했다. 기존 통합 생명주기 VM은 새 모듈을 실제 로드하도록 fixture 목록만 갱신했다.
- 390/1280px 주간·야간 화면에서 카드·파일 입력·가로 스크롤 표·버튼 경계를 확인했다. 개인정보 원문을 화면에 표시하지 않고 업무 열만 검토한다.

중간 전체 검사에서 변경하지 않은 사진 묶음 테스트가 정상 응답의 2ms 타이머와 25ms 타임아웃의 실행 순서에 의존해 반복 실패했다. 정상 응답을 비동기 microtask로 제어하도록 **테스트 fixture만** 수정했다. 무응답 사진은 실제 타임아웃을 유지하고 대체 1장·전체 12장·동시 요청 2~3개 조건을 확인한다. 해당 28개 검사와 최종 전체 검사가 통과했다. 사진 제품 코드는 변경하지 않았다.
