아래 다섯 묶음은 앱·서버 소스와 회귀 검사에 반영했다. 정적 앱 배포와 실제 Firebase 운영 활성화는 별개다. 업무 사용 절차는 [운영 안내](operations-guide.md), 서버 설정은 [보안 운영 안내](security-operations.md)를 따른다.

## 2026-10-25 기능 검토 후 추가 구현

기준은 밝기 보완 기능까지 반영한 `fcf91d210ec35e217089a9697ce648e47f8c67fd`이다. 사용자의 추가 구현 요청에 따라 다음 항목을 연결했다.

| 검토 이력 | 전체 후보·조건·모델 설정·입력 버전과 지문, 관찰 일치/불일치 비교, 전체 JSON·CSV, 한도 초과 시 명시적 거절 |

| 저장·조회 | 작업별 초안과 저장 버전 충돌 확인, 늦은 저장/사진 응답 보호, 커서 페이지, 실제 쿼리 결과 변경 시에만 로컬 구독 갱신 |

| 운영·복원 | 오류 후 감사 조회 자동 반복 중단, 캐시 출처 유지, 실패한 기간 내보내기 차단, 서버 실행 상태, 원작성자/재고/불변 이력을 검증한 관리자 복원과 대량 이전 재개 |

추가 회귀는 실제 브라우저의 재확인 완료·자료 반입·신고 연결·조건별 내보내기·사진 120장 출력·화면 이동, 초안 충돌·기관 자료 보존·복원 preflight 및 응답 유실, Firebase 규칙·서버·대량 이전을 포함한다. `check.mjs`, 서버 단위 검사, `check-emulator.cjs`, 여덟 브라우저 스크립트를 CI에 연결했다.

밝기 모델의 계수는 현장 데이터 없이 자동 변경하지 않는다. 외부 시설 존재와 실제 야간 점등을 구분하며 자료 공백을 실제 어두움으로 단정하지 않는다. Firebase 실운영 프로젝트 연결·함수 배포 및 실제 현장 정확도 검증은 별도 항목이다.

## 완료 조건

- 저장 재시도, 동시 탭, 늦은 비동기 응답으로 기록·초안이 사라지지 않는다.
- 기간 조회·백업은 완전성을 확인하고, 실패·부분 결과를 성공으로 표시하지 않는다.
- 공개 접수·직원·관리자 경계를 서버에서 강제하며 검수 증빙을 확인한다.
- 센서·GIS는 문서화된 좌표계와 실제 기하 거리를 사용한다.
- 초안 복구, 저장 대기함, 작업 배정·조치·검수, 미점검·방문 계획, 대장 변경 미리보기를 실제 UI에서 사용할 수 있다.
- Firebase 등 외부 인프라가 미설정이면 해당 기능의 연결 필요 상태를 표시한다.

## 통합 검증에서 추가 보완한 항목

- 새 화면이 열리거나 새 순찰이 시작된 뒤 늦게 끝난 저장은 해당 새 작업을 지우지 않는다.
- 초안 폐기는 진행 중인 자동 저장을 정리한 뒤 실행한다. 폐기한 작업 ID는 다시 사용하지 않는다.
- 새로고침 후 초안 복구가 끝난 다음 시설 점검 화면을 연다.
- 재검수 비용은 `costDelta`로 기록한다. 200 → 300 → 50이면 기간별 조정은 200, 100, -250이며 누계는 50이다. 과거 검수 이벤트는 변경하지 않는다.
- 재고와 연결 신고를 읽은 뒤 다른 직원이 변경하면 검수를 충돌 상태로 보존해 최신 자료를 확인하게 한다.
- 대장을 연속 갱신할 때 마지막 대장 값을 기준으로 실제 현장 수정만 충돌로 분류한다.
- 실시간 갱신으로 신고 입력, 방문 선택, 커서 위치가 사라지지 않게 보존한다.
- 브라우저 검사는 IndexedDB·서비스 워커의 비동기 작업이 실제 완료된 것을 확인하고 진행한다.

## 외부 환경 확인이 필요한 항목

운영 Firebase 프로젝트·승인 계정 UID·App Check·Functions 배포·예약 작업의 활성화, 실제 연락처와 보존 정책, 실제 Android/iOS 센서와 장시간 오프라인 동작, 관리 경계 및 실측값 대조는 코드 구현과 구분해 기록한다. 기본 OSM 타일 서버의 지역 일괄 다운로드는 제공하지 않는다.

## 확장 항목의 구현 원칙

- 방문 계획은 직선 거리 기반 방문 순서를 명시하며 차량 통행 경로로 표현하지 않는다.
- 밝기 예측과 사용자가 입력한 조도계 실측값을 구분한다.
- 중복 신고·사진 품질·반복 장애는 확인 후보로 제시하고 업무 상태는 담당자가 결정한다.
- 대장 갱신은 시설 ID를 유지하고 현장 수정과 충돌하는 항목을 미리 보여 준다.
- 자동 주민 메시지 발송은 설정과 별도 운영 승인 없이 실행하지 않는다.
