# Map Marker Reliability Implementation Plan

**Goal:** 검토에서 확인한 마커 중첩 선택, 순찰 화살표, 필터/검색 선택, 추정 좌표의 조명 범위 표시를 바로잡는다.

**Architecture:** 배포된 v64를 기준으로 지도 표시와 선택 상태만 수정한다. 화면상 겹친 시설을 숫자로 묶고 기존 지도 카드 안의 목록에서 개별 시설을 선택한다. 지도 인스턴스·선택 순번·현재 표시 대상을 확인해 늦은 검색 선택을 거절한다. 순찰 화살표는 부모 회전과 합성해 실제 진행 방향을 표시하고, 밝기 범위는 모델과 동일한 시설만 그린다.

**Tech Stack:** 기존 JavaScript·Leaflet·CSS, Node test runner, Playwright. 서버·업무 payload·시설 원본 좌표는 변경하지 않는다.

---

1. 주지도 회귀를 `scripts/marker-selection-browser-smoke.cjs`에 추가해 실제 동좌표 39시설, 가까운 시설, 선택 목록, 필터·검색·닫기·지도 교체의 늦은 선택을 먼저 실패시킨다.
2. `app/staff-app.js` 주지도에 화면 거리 기반 묶음과 개별 선택 목록을 구현한다. 목록은 종류·표찰·상태·추정 위치 안내를 제공한다. 방문 계획은 원래 순서·완료·다음 표시를 유지한다.
3. 종류·상태·범례 변경 시 카드와 대기 선택을 정리하고 검색·내 주변 결과를 현재 필터로 다시 그린다. 늦은 선택과 표시 범위 밖 선택을 차단한다.
4. 별도 테스트가 먼저 실패한 뒤 순찰 자동차의 로컬 회전을 실제 heading으로 고친다. 부모 회전과 합성한 결과를 검사한다.
5. `app/lighting-review.js`의 범위 원 대상을 모델과 맞추고 추정 좌표 제외 이유를 설명한다. 원본 대장과 모델 입력은 바꾸지 않는다.
6. 배포본 코드·신규 및 관련 지도 브라우저 검사, 독립 검토를 통과한 뒤 앱/SW를 v65로 맞춰 게시한다. 공개 자산과 실제 영상·마커 동작을 확인한다.
7. 별도 v61 개발본에는 해당 지도 함수·CSS·검사만 동기화하고 기존 업무·규칙 개발분을 보존한다.
